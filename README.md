# Cybersecurity Projects

## Overview

This repository contains a collection of projects exploring cybersecurity concepts using machine learning and data analysis. The focus is on understanding how data-driven techniques can be applied to detect anomalies, classify threats, and identify suspicious behavior.

## Projects

### 1. Log Anomaly Detection

* Detects unusual patterns in system logs
* Uses time-window based feature engineering
* Implements unsupervised anomaly detection techniques
* Simulates basic log monitoring workflows

---

### 2. Threat Classification

* Classifies data into different categories (e.g., normal vs malicious)
* Uses supervised machine learning models
* Focuses on pattern recognition in structured data

---

### 3. Phishing Email Detection

* Detects phishing/spam messages using NLP techniques
* Uses TF-IDF vectorization for text processing
* Incorporates domain-specific features:

  * Suspicious keyword detection
  * URL/link detection
  * Message length analysis
* Evaluated using accuracy, confusion matrix, and visualizations

---

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## Notes

These projects are developed for learning and exploration purposes. The emphasis is on building clear pipelines and understanding cybersecurity-related data rather than creating production-ready systems.
